# SneakySneek 

SneakySneek is a simple sneaker-selling website built using HTML, CSS, and JavaScript. It allows users to explore sneakers, select sizes, add products to a cart, and proceed to a demo checkout.

## Features
- Landing page and featured sneaker display
- Size and quantity selection
- Add and remove items from cart
- Order summary and coupon discount
- Demo checkout and payment interface
- Responsive design

## Technologies
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Run `index.html` using Live Server or your browser.

This is a student project for educational purposes. Payments are not processed.
